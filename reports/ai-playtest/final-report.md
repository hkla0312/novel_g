# 『アカノユメ』AIテストプレイ最終レポート

## 1. 方法と制約

- 現行の `choose / enterNode / getAvailableChoices / Condition / Effect` を直接使用した。
- seed固定の20ペルソナを各500周、合計10,000周実行した。うち初回状態9,500周、TRUEクリア履歴あり500周。
- ペルソナは取得済み本文・GameState・ARCHIVEだけを参照し、未取得ノードやEND条件を参照しない。
- 思考ログは内部推論ではなく、取得済み状態から説明できる `CURRENT HYPOTHESIS / CONFIDENCE / REASON / NEXT INTENT` の短い記録。
- この集計は人間の読解そのものではない。選択重みへの感度があるため、END比率は絶対値ではなく偏り検出に使う。

## D. キャラクター理解

### 老人

`neighbor_home_hub` と `neighbor_life` は、黒幕扱いを一度弱める材料として有効。`neighbor_red_objects` と `neighbor_old_paper` で疑念が戻る流れも自然。ただし `neighbor_late_boundary` の到達率が低く、老人が「害を与えた事実」と「救いを求めた受信者」の両方を持つ理解は少数に留まる。

### 母

PROLOGUEの傷害と、ACT5の普通の帰宅の対比は最も強い場面の一つ。ただし母の内面化過程を最終的に理解した状態は1.5%。`mother_room_first` のknowledgeは取得されても、ACT5で意味を結び直すにはTRUE条件が重い。

### 義弟

敬語、仕事と自己価値への不安、「一人で抱えなくていい」は自然。万能解説役にもなっていない。一方、ACT4の必須会話まで赤い夢を聞かなかったrunでも、本文では聞くのにstateへ保存されていなかった。これは修正済み。

### 主人公

恐怖→身体反応→整理の順は起床場面で成立。後半の `pc_town`〜`author_reveal` は静かで強い。ただしACT4到達者全員が同じ答えへ一気に達するため、それ以前の探索差が作者発覚後の理解に与える影響はEND条件以外では薄い。

## E. 問題点

### CRITICAL

なし。softlock、欠損遷移、初回SECRET漏洩、セーブ破損、ARCHIVE先行開示は検出されなかった。

### HIGH

1. `ending_junction` / TRUE条件
   - 問題: 初回TRUE 0.1%。目標15%から大幅に低い。
   - 誤認: 深読み・全探索ペルソナでもNORMALへ入り、「理解選択をしたのに通常END」と感じやすい。
   - 原因: 地還し、老人生活、事件接続、境界、SELF4、義弟理解、母同行・共感の全AND。16:00前に老人宅・図書館・自宅再探索を高密度で取る必要がある。
   - 推奨: 条件を減らす前に、人間プレイテストで各必須条件の脱落数を表示せず記録する。特に `neighbor_injury_faith_possible_link` と `neighbor_faith_contained_after_loss` の両必須を再検討。
   - 影響: END分布、再プレイ意欲、母・老人理解。

2. `act2_hub`〜`old_room_headset_memory` / Mina導線
   - 問題: Mina連絡0.3%。SECRET以前に通常プレイでほぼ会えない。
   - 誤認: Minaが存在すること自体に気づかない。ACT4で突然名前が出たように感じる可能性。
   - 推奨: timeCostはまだ変えず、Mina解放に必要な各条件の未達率をUI非表示でtelemetry化。次回人間テスト後、SELF2＋A4＋部屋再探索のどこを緩めるか判断。
   - 影響: ACT4の感情的厚み、SECRET到達可能性。

3. `neighbor_late_boundary` / `mother_empathy`
   - 問題: H9 19.9%、H11 1.5%。老人と母の鏡構造が大半へ届かない。
   - 誤認: 「老人が広げた危険信仰」「母は洗脳された」のままNORMALへ進みやすい。
   - 推奨: TRUE条件緩和とは別に、NORMALでも取得済みの妻・介護情報へ短く反応するvariantを検討。答えを説明せず、母が最初は仏間を怖がった証言を再想起させる程度。
   - 影響: 主題理解。

### MEDIUM

1. `free_action_hub`
   - 病院・警察が完了後も同じ内容で再選択可能。無意味な時間消費と選択ノイズになる。
   - 推奨: 完了後は非表示、または「再度相談する」にvariant化しtimeCost／内容を変える。

2. `verify_police`
   - 正式確認だけで傷害事件まで客観確認されるため、おばちゃんの噂を聞く価値が薄く、H2材料がほぼ全員へ届く。
   - 推奨: 警察ルートの高い時間コストに見合う一方、噂→部分確認→仏間の順を重視するなら、警察が伝える範囲を一段分ける。

3. `act3_hub`〜`author_reveal`
   - PCは必須でH8が100%。探索差にかかわらず作者関係が同じテンポで確定する。
   - 推奨: 発覚自体は維持し、取得knowledge別variantで「何が驚きなのか」を変える。現在もPC発見variantはあるが、解釈variantは少ない。

4. `brother_call`
   - 本文で赤い夢を聞いてもknowledgeへ保存されない不一致があった。今回 `brother_red_dream` 付与を追加して修正済み。

### LOW

1. `freeActions.ts` / `act3to5.ts`
   - 「噓」「詤曲」「變形」という文字化け・異体字が残っていた。今回「噂」「改変」「変形」へ修正済み。
2. `home_old_room` / `old_room_repeat`
   - CD-Rは現状、設定上の役割がなく「中身を読む準備が必要」とだけ示される。以前の仕様意図が未確定なら削除候補。今回は物語変更を避けて残した。
3. `compare_custom_and_paper`
   - 地還しとA4の比較説明は明快だが、地還しを精査済みのプレイヤーには一部重複する。削るなら一文だけで十分。

## F. 精読評価（代表ルート8本）

- 主人公の口調: 一貫している。負傷直後の短文と後半の分析文の差も自然。
- 母: 普通の会話と歪んだ認識の同居が成立。怪物化・邪教口調はない。
- 義弟: 敬語と沈んだ人物像が成立。`brother_understand` が最も人物評価を変える。
- 妹: 質問形式で証言を段階化できている。設定資料感は初期版より弱い。
- おばちゃん: 噂の曖昧さは自然。正字修正前のタイトルだけ品質を損ねていた。
- 老人: 日記説明を避け、写真・年賀状・椅子・眼鏡ケースで再解釈させる構造が良い。
- 地還し: `library_jigaeshi` は情報量が多いが、アカノユメとの差分を作る役割上は許容範囲。
- Mina: 到達すれば便利すぎない。ただし到達率が低すぎ、評価母数そのものが不足。
- ホラー: ジャンプスケアなし。最も強いのは `final_call` と `mother_returns_evening`〜`mother_go_together` の日常会話。
